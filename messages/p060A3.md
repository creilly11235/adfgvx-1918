# p060A3

Childs page 57, 20 September 1918. Key sep19. Status Read. Read with the published keys.

Detail. Known key reading from two blind readings of the page, confidence reading with 0 open positions. Read with Lasry's published keys. The page symbols were read twice blind and agree on every letter, so the ciphertext shown is the agreed page reading. Open positions are marked in the text. Read with a published key, and whether anyone read it earlier is not confirmed.
